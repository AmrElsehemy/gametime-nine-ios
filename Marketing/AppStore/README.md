# Exactly One App Store launch assets

Source of truth for the v1 visual pack.

- `Icon/` — shipping 1024×1024 app icon
- `GameCenter/` — four 1024×1024 achievement images
- `Screenshots/` — screenshot story/copy; final images must come from the real build
- `Preview/` — optional App Preview decision and future capture
- `ASSET_MANIFEST.md` — release status

The icon and Game Center art are reproducibly generated by `Tools/generate_launch_assets.py` and the app icon is compiled from `Nine/Assets.xcassets`.
