# Approved launch visual direction

The approved v1 direction is **Tactile Territories / Pebble**.

Shipping visual rules:
- warm tactile irregular territories
- central polished Pebble language
- no crown/queen/chess visual metaphor
- no text embedded in the app icon
- achievement badges use the same material/tactile family
- generated concept mockups are reference only; App Store screenshots must be captured from the real shipping build

The reproducible source of truth for the icon and Game Center badges is `Tools/generate_launch_assets.py`.
