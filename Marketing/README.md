# Game #001 Marketing Assets

This directory owns launch and growth assets derived from production gameplay.

## Planned structure

```text
Marketing/
├── AppStore/
│   ├── Screenshots/
│   ├── AppPreview/
│   └── Copy/
├── Social/
│   ├── 9x16/
│   ├── 1x1/
│   └── 16x9/
└── Capture/
    ├── Replays/
    └── SourceClips/
```

## Rule

Marketing must represent real gameplay. Avoid mock gameplay that cannot be reproduced in the shipped app.

## Initial capture moments

- first satisfying tutorial solve
- clean full-board solve
- fast solve
- no-hint solve
- difficult-board completion
- streak/daily-result celebration

The gameplay/replay system should eventually emit semantic marketing markers so these moments can feed automated capture and Remotion workflows.
